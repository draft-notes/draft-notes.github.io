    Writing

    Formatting

    The formatting bar, colours, highlights and text effects.

    The formatting bar

    Select some words and a glass bar appears right above them, with bold, italic, underline, strikethrough, links, colours and effects. It flips below the selection near the top of the window. You can see it on the Features page.

    Format Shortcut
    Bold ⌘B
    Italic ⌘I
    Underline ⌘U
    Strikethrough ⇧⌘X
    Inline code ⌘E
    Link ⌘K
    Reapply last colour ⇧⌘B

    Inline Markdown works too: type **bold** and Draft formats it as soon as you close it.

    Colours and highlights

    Open the palette from the bar. Pastel squares are highlights; circles are text colours. Your selection stays put while you choose.

    Text effects

    Effects make a few words stand out: Accent, Gradient, Glow and Spectrum, a slowly moving gradient. Each effect has a strength, and Gradient lets you set your own colour stops in the gradient editor.

    Effects respect Reduce Motion: Spectrum stops moving and keeps its colours.

    Block fonts

    Format → Block Font sets a single block to System, Serif, Mono or Rounded. It wins over the note’s font; code stays monospaced.
