    Roadmap

    Where Draft is going.

    Writing first, then structure, style, finding and recovering, before anything that needs a server or other people. This page is generated from the plan the app is built against.

    1. v0.1 Shipped

      First light

      A runnable native vertical slice proving the architecture.

      10 items · 10 done
      • ✓ Native window: full-height rail, top tab strip, All Docs home; tabs persist across restarts.
      • ✓ New document in one action (⌘N); typing starts in the title; content persists across quit/relaunch (smoke test).
      • ✓ Blocks: paragraph, Title/Subtitle/Heading/Strong/Caption, quote, code, bullets, numbers, checklist (nested), separators, links, images (vault assets, paste or pick), nested pages as cards/pages.
      • ✓ Markdown triggers (#…####, -, , 1., [], [x], >, , ---, b, i, ~~s~~, ==h==, c ) — undo restores literal text.
      • ✓ Floating selection toolbar with in-place color palette and link field; flip/clamp; Esc; ⌥F10.
      • ✓ Aa Format panel; Style panel (backdrop solid/gradient/scenic/upload, blur, immersive/faded, page and text color with contrast warning, cover, separators, fonts); Style Gallery; 7 original styles.
      • ✓ Document rail: Outline, Tasks, Attachments, Find & Replace.
      • ✓ Library: gallery / grid / list, search titles + text, sort name/updated/created/viewed, folders, Unsorted, Starred, Quick Open (⌘O).
      • ✓ Export: Markdown + assets + lossless draft-export.json; copy Markdown; print (→ PDF via dialog).
      • ✓ Light/dark/system, accent, document-tinted shell, reduce motion; narrow-window layout.

    2. v0.2 Shipped

      Writer's desk

      Single-document writing that feels finished and safe.

      6 items · 6 done
      • ✓ Block gutter handle, drag reorder with insertion line and autoscroll, block selection (Esc, ↑/↓, ⇧↑/↓), delete blocks, Move up/down/top/bottom (⌥⌘↑/↓, ⌃⌥⌘↑/↓). One undo per operation.
      • ✓ Paste: multi-line text → one block per line with Markdown recognized; RTF/HTML → headings, lists and marks; Draft → Draft keeps blocks and marks; surrounding block keeps its id.
      • ✓ Recently Deleted for documents and nested pages: Undo toast, Restore, Delete Permanently, Empty, 30-day purge.
      • ✓ Automatic local backups (≤ 1 per 10 min while editing, 30 kept) with View Backups → Restore.
      • ✓ Space Search: one result per doc, match count, highlighted snippet, opens the doc on the first match (Find in Page pre-filled).
      • ✓ Layout: text scrolls only below the document controls; the slash menu flips/shrinks to stay in the window (checked at 1440×900 and 720×640).

    3. v0.2.1 Shipped

      Writer's desk, continued

      9 items · 9 done
      • ✓ Block context menu (turn into, duplicate ⌘D, copy link, group, move, delete) on the handle and in the text's context menu; draft:// block links open the doc at the block.
      • ✓ Group selected blocks into a nested page (⌘G) / ungroup (⇧⌘G), ids preserved, undoable.
      • ✓ Move blocks to another doc (block menu → Move to), undoable on both sides.
      • ✓ Undoing a group / ungrouping no longer leaves a page in Recently Deleted.
      • ✓ Toggle list (+ , ⌘↩), callout block, page break (===, honored when printing), strong/dotted/three-dot separators, x task trigger.
      • ✓ Cover crop/reposition (Original, 16:9, 2:1, 3:1, 4:3, Free; keyboard nudging) stored as data.
      • ✓ Tab state across restarts (scroll + caret). ⬜ Back/forward stacks (moved to v0.3 with links).
      • ✓ Image block: resize (edge drag or S/M/L/Full), caption, alt text; file attachment block (picker, drag and drop, Finder paste; opens in its default app).
      • ✓ Performance pass with scripts/perf.sh (10,000 blocks, real app). Fixed: per-keystroke whole-window SwiftUI re-renders and full-document conversions (131 → 7 ms p50), full ID scans on Return (114 → 13 ms), block moves via direct paragraph cut/insert (382 → 14 ms), forced full layout on height changes, and search of text beyond the 50,000-character index. 🟡 Known limits (TextKit 1 contiguous layout): keystrokes that change wrapping (~20 ms p95) and toggles near the top of a 10k-block doc (~120 ms) relayout everything below → v0.8.

    10. v0.8 Planned

      Trust

      3 items · 2 done
      • ✓ Vault integrity checker and unused-file cleanup — first slice (12 Nov 2026). Scope: Settings › Data & Storage › Check Vault reads the vault without changing it and reports an unreadable library, notes listed without a file, note files the library doesn't know, note files that don't decode, attachments a note points to that are missing, and attachments no note uses (notes in Recently Deleted and templates count as users). Move Unused Files… asks first (count and size), moves them to backups/unused-<time>/ (never deletes) and one Undo moves them back. Acceptance: a throwaway vault with each kind of problem is reported exactly; moving and Undo restore the same bytes; nothing outside assets/ is touched; a read-only vault refuses the move. Performance: check 2,000 notes and 1,000 attachments in < 2 s, off the main thread, UI responsive. Accessibility: the report is a list VoiceOver reads row by row with counts; the move button names the count; confirmation is inline in the same row (Cancel, Escape, or Move to Backups) so it is visible in captures. Result: VaultCheckTests (each problem kind, same bytes after Undo, read-only refusal, 2,000 notes / 1,000 files in 0.4 s debug); vault-check probe in light and dark (docs/screenshots/v08/vault-check/). Screenshots: Data & Storage with a clean report, with problems, and the confirmation (light and dark).
      • ✓ Orphan cleanup for backups older than 30 days (manual, listed first — part of #8).
      • ○ Optional encryption at rest (later milestone).
