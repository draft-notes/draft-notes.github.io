    Assistant

    It reads what you point at.
    You approve what it changes.

    How Draft handles privacy

    Everyday

    The small things, done well.

    • Format as you go

      Markdown shortcuts, a glass formatting bar, highlights and text effects.

    • Tables and collections

      Edit cells in place; show the same items as a table, gallery or board.

    • Links and tags

      Type [[ to link a note and # to tag it; backlinks show what points back.

    • Tasks and days

      Tasks with due dates next to the words they belong to; daily notes and a calendar.

    • Export anywhere

      Markdown, a styled web page, PDF, an image, or a whole static site.

    • Backups built in

      Local history for every note and Recently Deleted, on your Mac.
