    Changelog

    What's new in Draft.

    Every release, newest first. What's coming next is on the roadmap.

    1. Draft 0.11.0Latest

      • Folders nest: New Subfolder in a folder's menu.
      • Drag a note from the board or the sidebar onto a folder to move it.
      • Focus Mode in the rail menu; Present from Info.
      • Check for Updates, backup archives, Help and Privacy centers from earlier builds.
      Download

    2. Draft 0.10.1

      • Test build for the hosted update path: delivered through Check for Updates.
      • No note, Space or setting changes.

    3. Draft 0.10.0

      • Check for Updates in the Draft menu; automatic checks stay off until you turn them on
      • Help with searchable how-tos that open the right setting
      • Report a Problem writes a local report you review; nothing is sent
      • Privacy settings list every permission and network feature
      • Backup archive: the whole vault in one file you can restore and check
      • Import preview with duplicates before anything is added

    Earlier versions

    • v0.5.1One app, and a local Assistant
    • v0.5StructureStructured information inside documents: collections with views, simple tables,
    • v0.4Style studioMake documents look the way you want and export them the way they look.
    • v0.3Linked thinkingNotes that know about each other and about time: links, backlinks, tags, daily notes,
    • v0.2.1Writer's desk, continued
    • v0.2Writer's deskSingle-document writing that feels finished and safe.
    • v0.1First lightA runnable native vertical slice proving the architecture.

    Details of each earlier version are on the roadmap.
